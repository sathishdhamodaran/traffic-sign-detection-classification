## Dataset Setup

### GTSRB (for `01_recognition.ipynb`)

Download from: https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign

After extracting, the folder should contain: `Train/`, `Test/`, `Meta/`, `Train.csv`, `Test.csv`, `Meta.csv`

### GTSDB (for `02_detection.ipynb`)

Download from: https://www.kaggle.com/datasets/icebearogo/german-traffic-sign-detection-gtsdb-dataset

After extracting, the folder should contain: `GTSDB_Train_and_Test/Train/images/`, `GTSDB_Train_and_Test/Train/labels/`, and equivalent `Test/` folders.

In **both notebooks**, the dataset path is defined near the top. Update it to match your local path:

## How to Run

### Recognition notebook (`01_recognition.ipynb`)

Run all cells **sequentially from top to bottom**. The notebook is self-contained — it loads data, runs EDA, trains all models, and evaluates each one on the GTSRB test set (12,630 images).

Models train in this order:
1. Baseline CNN (~5 min)
2. ResNet-18 v1 and v2 (~15 min combined)
3. MobileNetV2 v1 and v2 (~15 min combined)
4. CNN+ANN (~10 min)
5. EfficientNet-B0 Stage 1 + Stage 2 (~15 min)

**Total runtime: approximately 60–90 minutes** on an RTX 4060.

A full comparison table is printed at the end of the notebook.

### Detection notebook (`02_detection.ipynb`)

Run all cells sequentially. This notebook:
1. Explores the GTSDB dataset
2. Trains YOLOv8 single-class detection (~20 min)
3. Evaluates detection metrics (mAP, precision, recall)
4. Runs the full pipeline: YOLOv8 detects signs → Baseline CNN classifies them

> **Note:** The detection notebook loads the trained Baseline CNN weights from `best_baseline_cnn.pth`. This file is generated by the recognition notebook, so `01_recognition.ipynb` must be run first.

## Important Notes

- **Windows users:** DataLoaders use `num_workers=0` throughout. This is intentional — values above 0 cause Jupyter to freeze on Windows.
- **Saved weights:** Each model saves its best weights as `.pth` files in the working directory during training. These are loaded automatically for evaluation.
- **Class imbalance:** The dataset has a 10.7× imbalance between the largest and smallest classes. All models use weighted CrossEntropyLoss to address this.
- **Transfer learning models** (ResNet-18, MobileNetV2, EfficientNet-B0) download pretrained ImageNet weights on first run, which requires an internet connection.

## Hyperparameter Tuning — CNN+ANN (~2 hours for 15 trials)
- **Note:** The hyperparameter tuning cell runs 15 independent training trials 
- and takes approximately 2 hours. If time is limited, this cell can be skipped 
- without affecting the rest of the notebook — the tuning results are reported in the final report.
